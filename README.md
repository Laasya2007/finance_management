Finance Management System (DBMS Project)

A database-driven finance management system designed to store, manage, and analyze user transactions efficiently using a structured DBMS approach.

Key Features
- Structured storage of financial data using relational database concepts
- Efficient transaction management and retrieval
- Monthly report generation using database queries
- Data visualization based on stored database records
- CSV data import into database
- SMS parsing for automated transaction entry

Database Concepts Used
- Relational schema design
- Primary and foreign keys
- Data normalization
- Query-based data retrieval
- Transaction handling

Technology Stack
- DBMS (MySQL)
- Java (for UI and interaction layer)
- JDBC for database connectivity

System Modules
- User Management (Login/Register)
- Transaction Management
- Reporting System (Monthly, Charts)
- Data Import & Parsing

How to Run
1. Set up the database
2. Configure DB connection in DBConnection.java
3. Compile:
   javac *.java
4. Run:
   java Login
